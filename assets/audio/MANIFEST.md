# Audio manifest — Chapter 1

The game runs silently without these; AudioManager logs what's missing.
Drop files into `assets/audio/<kind>/<name>.ogg` (or `.wav`) and they play
with **no code changes**. Sourced audio must be license-safe (CC0 preferred;
CC-BY with attribution recorded in `CREDITS.md`). Good sources: freesound.org
(filter License: CC0), kenney.nl (CC0), opengameart.org.

## music/
| file | description |
|---|---|
| `title_theme` | Sparse, low, cold — a held string or drone, not heroic. 1–2 min loop. |

## ambient/ (loops)
| file | description |
|---|---|
| `hardstand_dawn` | Pre-dawn airfield: wind, distant birds, a far generator or idling engine. |
| `bomber_interior` | Four-engine drone from inside the fuselage, constant, heavy. |
| `wind_descent` | High wind, canopy flutter, distant nothing. |
| `night_interior` | Quiet room: fire crackle, occasional creak, distant dog far off. |

## sfx/
| file | description |
|---|---|
| `m2_shot` | Single .50-cal report, close and mechanical (played per shot, pooled). |
| `flak_close` | Muffled heavy thud with rattle — a burst near the airframe. |
| `chute_open` | Sharp fabric snap + jolt. |
| `distant_gunfire` | A ragged rifle/MG volley from far below. |
| `impact_thud` | Body hitting earth, heavy, dull. |

Search-term suggestions: "b17 interior", "bomber engine loop", "50 cal single",
"flak", "parachute deploy", "wind howl loop", "fireplace crackle room tone",
"distant machine gun".
