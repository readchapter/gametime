# Audio manifest — Chapters 1–2

**Every slot below currently ships with a synthesized placeholder** (WAV,
generated by `tools/synth_audio.py` — license-free, regenerate any time).
They're real sound design (layered noise/drones/envelopes), but sourced
recordings will beat them: drop a file with the same name into
`assets/audio/<kind>/<name>.ogg` (or overwrite the `.wav`) and it plays with
**no code changes**. Sourced audio must be license-safe (CC0 preferred;
CC-BY with attribution recorded in `CREDITS.md`). Good sources: freesound.org
(filter License: CC0), kenney.nl (CC0), opengameart.org.
